# Architecture Decision Records

ADR registra uma decisão arquitetural, suas alternativas e consequências. O
objetivo não é criar uma arquitetura definitiva antecipadamente.

## Estados

- Proposed: aguardando avaliação.
- Accepted: aprovado e evidenciado.
- Superseded: substituído por outro ADR.
- Rejected: rejeitado com justificativa.
- Deferred: ainda sem condição suficiente.

Nenhuma decisão deste diretório deve ser tratada como aceita sem status
explicito.
